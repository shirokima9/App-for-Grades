# درجاتي — تطبيق إدارة درجات الطلاب

تطبيق ويب (PWA) لإدارة درجات الطلاب يعمل **محليًا بالكامل** على جهازك — بلا سحابة، بلا إنترنت، بلا أي إرسال بيانات لأي جهة.

## المتطلبات

- Node.js إصدار 18 أو أحدث (يُثبَّت مرة واحدة).
- التثبيت الأول يحتاج إنترنت لتنزيل الحزم؛ بعدها يعمل التطبيق والجهاز غير متصل تمامًا.

## التشغيل

```bash
npm install        # مرة واحدة فقط
npm start          # يبني الواجهة ويشغّل الخادم
```

عند التشغيل ستظهر في الطرفية روابط الوصول مع **رمز QR** لكل شبكة متاحة.

## الوصول من الجوال

1. شغّل نقطة اتصال من جوالك ووصّل اللابتوب بها (أو اجعلهما على نفس شبكة Wi-Fi).
2. شغّل `npm start` — سيظهر رابط مثل `http://192.168.x.x:4750` مع رمز QR.
3. امسح الرمز بكاميرا الجوال وافتح الرابط.
4. من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية"** ليعمل كتطبيق.

## استيراد الملف الوزاري

1. من الشاشة الرئيسية أنشئ الشعبة (الصف + اسم الشعبة).
2. افتح **استيراد** واختر ملف الإكسل الوزاري.
   - **الملف الأصلي يُقرأ فقط ولا يُكتب فيه أبدًا.**
3. راجع **تقرير المسح البنيوي**: الأوراق وحمايتها، صف العناوين المكتشف، الأعمدة (قيم أم معادلات)، قواعد التحقق، ونطاق صفوف الطلاب.
4. طابق الأعمدة يدويًا (اسم الطالب، أعمدة الدرجات...) واحفظها **كقالب** حتى لا تكرر المطابقة.
5. راجع **تقرير مطابقة الأسماء**:
   - تطابق تام: يُقبل تلقائيًا.
   - تطابق قريب: لن يُقبل أبدًا دون تأكيدك يدويًا.
   - بدون تطابق: تقرر أنت (طالب جديد أو تخطي).
   - **لا يمكن تثبيت الاستيراد وهناك حالة واحدة غير محسومة.**
6. عند إعادة استيراد ملف محدَّث يظهر تقرير فروقات: من أُضيف، من حُذف، من انتقل.

## أين تُحفظ بياناتي؟

كل شيء داخل مجلد المشروع فقط:

| المجلد | المحتوى |
|---|---|
| `data/school.db` | قاعدة البيانات (الطلاب، الدرجات، الملاحظات، القوالب) |
| `backups/` | نسخ احتياطية تلقائية قبل كل استيراد أو كتابة |
| `exports/` | نسخ العمل الخاصة بك (xlsx) |
| `submissions/` | نسخ التسليم الوزارية |
| `data/uploads/` | نسخ للقراءة من الملفات المستوردة |

## استرجاع نسخة احتياطية

النسخ في `backups/` باسم يتضمن التاريخ والسبب، مثل `school-2026-08-13T12-45-30-import.db`:

```bash
# أوقف التطبيق أولًا (Ctrl+C) ثم:
cp backups/school-<التاريخ>-<السبب>.db data/school.db
npm start
```

## اختبار سريع بالملف التجريبي

```bash
npm run make:sample   # ينشئ samples/ministry_sample.xlsx
```

ملف يحاكي الملف الوزاري: ترويسة مدرسة علوية، معادلات مجموع وتقدير، تحقق من صحة البيانات (0–20)، قائمة منسدلة، ورقتان محميتان، و25 طالبًا بأسماء رباعية بعضها متقارب عمدًا لاختبار المطابقة.

## الخصوصية

- لا CDN، لا خطوط من الإنترنت، لا تحليلات، لا أي استدعاء API خارجي.
- الخط العربي (Cairo) وكل المكتبات مضمَّنة داخل المشروع.
- بيانات الطلاب لا تغادر جهازك إطلاقًا.
